# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-04-23

### Added

- Initial project structure and tooling
- TypeScript strict mode with ESM
- ESLint flat config + Prettier
- Vitest for unit + integration + E2E testing
- GitHub Actions CI pipeline
- CLI stubs for `mao-scaffold` and `mao-activate`
- Source module stubs: config (schema, loader, presets, defaults), engine (renderer, helpers, context, catalog, scaffold, writer, snapshot, validator), utils (fs, logger)
- Sample PRD fixture (TaskForge project management platform)
- Sample config fixtures (fullstack, minimal, invalid, needs-review)
- Catalog directory with conventions documentation
- Community skills directory with contribution guide stub
- README with project vision and quick start
- MIT License
